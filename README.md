📱 Tseki - AI Assessment Generator & Automated Camera-Assisted Grader
An ongoing BSIT Capstone Research Project at Cebu Eastern College

Targeting the device gap and manual grading inefficiency for primary educators in resource-constrained environments.

🔬 Project Abstract
The primary bottleneck this research addresses is the manual grading inefficiency and the lack of accessible, personalized diagnostic analytics for primary educators. Tseki is a mobile platform that leverages Google Gemini for dynamic assessment generation and Gemini Vision OCR / YOLOv8 for automated test grading.

This project is actively developed using Google Antigravity as the primary IDE to streamline complex API integrations and rapid mobile prototyping.

✨ Core Features
Generative AI Assessments: Instantly generate mixed-format quizzes (Multiple Choice, True/False, Identification) based on curriculum topics using Google AI Studio.
Human-in-the-Loop Override: Built-in manual override allowing educators to seamlessly append custom questions alongside AI-generated content.
Automated OCR Grading: Camera-assisted assessment grading leveraging Vision AI to instantly read and score student papers.
Performance Tracking: Cloud-synced diagnostic analytics for tracking student progress over time.
